# Currency Converter

A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript. The application allows users to convert an amount from one currency to another using real-time exchange rates fetched from an external API. Country flags automatically update based on the selected currencies, providing a clean and intuitive user experience.

---

## Features

* Real-time currency conversion
* Supports a wide range of international currencies
* Dynamic country flag updates
* Default conversion from USD to INR
* Responsive and clean user interface
* Input validation for invalid amounts
* Error handling for API failures
* Fast and lightweight implementation

---

## How It Works

1. User enters an amount.
2. Selects source currency.
3. Selects target currency.
4. Clicks on "Get Exchange Rate".
5. Application fetches live exchange rates from the Currency API.
6. Converted value is displayed instantly.
7. Country flags update automatically when currencies are changed.
